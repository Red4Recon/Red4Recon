> ## 🧠 About Astra
>
> Astra is my core AI assistant workspace — a voice-first macOS dictation and assistant app built with Electron and TypeScript, with an iOS app and keyboard. It's based on the open-source [Jarvis AI Assistant](https://github.com/akshayaggarwal99/jarvis-ai-assistant) project and is the launchpad for the apps I'm building.
>
> **Key capabilities:**
>
> - 🎙️ Voice dictation & transcription (local Whisper / NVIDIA Parakeet, or cloud Deepgram)
> - 🤖 Local LLM support via Ollama (fully private), or cloud Gemini
> - 🍎 Platforms: macOS desktop app, plus an iOS app and keyboard
> - 🔌 Modular — easy to extend with new skills and integrations
> - 📖 MIT licensed — open source
