> ## 🧠 About Astra
>
> Astra is my core AI assistant platform — a voice-first, privacy-focused AI that runs locally or in the cloud. It's the launchpad for every app I'm building.
>
> **Key capabilities:**
> - 🎙️ Voice dictation & transcription (local Whisper / cloud Deepgram)
> - - 🤖 Local LLM support via Ollama (fully private)
>   - - 🌐 Cross-platform: Mac, iOS, Windows (coming)
>     - - 🔌 Modular — easy to extend with new skills and integrations
>       - - 📖 MIT licensed — open source forever
